# RTT 표본과 임계값

관리자 화면의 `RTT 기준 설정`을 펼칩니다. 완료된 인증을 선택하고 실제로 사용한 경로에 맞게 Direct 또는 Relay로 등록합니다. 인증당 평가 10회의 중앙값을 1개 표본으로 사용합니다. 같은 인증을 중복 등록해도 표본은 늘지 않고 경로 라벨만 바뀝니다. 잘못 등록했거나 튀는 표본은 하나씩 제외할 수 있습니다. 인증으로 등록한 표본은 `인증 선택` 옆 `제외`로, 반복 수집 표본을 포함한 전체는 `등록 표본 제외` 목록(라벨별 RTT 큰 순)에서 골라 제외합니다. `표본 초기화`는 별도 평가 기록과 적용 임계값까지 모두 지웁니다.

추가·제외 시 등록 표본 전체에서 90% 탐지 목표 임계값 후보를 자동 계산합니다. 등록 표본 개수 하한은 없습니다. Relay 0개는 계산 불가, Direct 0개는 정상 오판율 계산 불가입니다. Relay가 1개여도 계산됩니다.

정렬한 Relay n개 중 ceil(0.9*n)개 이상이 엄격한 `RTT > T`를 만족하도록 경계값 바로 아래의 가장 가까운 부동소수점 값을 사용합니다. 동률이나 작은 n에서는 탐지율이 90%를 초과할 수 있습니다. 표시용 소수점 반올림은 판정에 사용하지 않습니다. 등록 표본의 비율은 독립 평가 정확도가 아닙니다.

`임계값 적용`을 누르면 현재 표본과 계산값의 스냅샷을 저장하고 이후 인증에 사용합니다. 후보값이 바뀌어도 이미 적용한 기준은 자동 변경하지 않습니다. 기존 인증 결과도 재판정하지 않습니다. 서버 재시작 후 유지됩니다. 적용한 UI 기준은 RTT_THRESHOLD_MS 환경변수보다 우선합니다. 원시 RTT와 워밍업 값은 계속 저장합니다.

중계 영상: 프록시에 --trace 옵션을 추가하면 메시지 종류와 전달 방향만 표시합니다. 이미지·토큰·학생 정보는 로그에 찍지 않습니다. 로그 출력도 처리 시간에 영향을 줄 수 있으므로 표본 수집과 시연에서 같은 로그 설정을 유지하세요. 별도 지연 주입 기능은 추가하지 않았습니다.
